## 比较条件

使用 Codex 内置浏览器，参考页面在 8098，运行版在 8097。桌面 CSS 视口为 1440×1000，截图配对尺寸一致，设备倍率约为 1。部分截图接口返回 1425×990 的内容区域，另一组返回完整 1440×1000；每个配对内部尺寸已校验。

对照文件包括教师首页、教师课堂、周课表、学生首页、学生课堂、辅导员首页和多维考勤。`*-comparison.jpg` 左侧为上传源码的原版，右侧为运行版。另有首页细节裁剪用于检查字体、插画和卡片间距。

运行版使用 MySQL 实训数据，原型使用浏览器演示数据；班级数量、课程教室、出勤颜色、申请条数和统计行数因此不同。原 CSS 的 `.main { margin:auto }` 会按内容高度居中，少量统计行时页面位置随内容高度变化。比较期间经过午夜，部分学生截图的日期从 10 月 14 日切换到 10 月 15 日。这些属于数据和时刻差异；源码结构检查用于排除额外布局替换。

已保留原 40 个图形座位，班级其余学生可在原考勤表中管理。后端没有因 UI 还原删除注册账号或考勤数据。
