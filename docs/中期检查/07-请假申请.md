# 请假申请

**优先级：重要。** 学生针对明确的课次提交请假，不能只提交一个模糊日期范围。

## 真实代码入口

- `ApiController.eligible(...)`：查询学生可选择的课次；
- `ApiController.apply(...)`：`POST /leave/applications`；
- `SchoolService.apply(...)`：在一个事务中创建申请和课次目标。

## 执行过程

1. 学生先获取自己在指定日期范围内的课次。
2. 前端把申请原因、日期范围和选中的课次 ID 提交给服务端。
3. 服务验证学生身份、日期范围、原因长度及每个课次均属于本人班级。
4. 事务插入 `leave_applications`，再为每一节选中课写入 `leave_targets`。
5. 服务通知可见的审批人；审批前申请为 `PENDING`，不会改变考勤结果。

## 向老师讲解的一句话

“请假目标精确到课次，后续自动缺勤 SQL 可以准确排除已经批准的那一节课。”
