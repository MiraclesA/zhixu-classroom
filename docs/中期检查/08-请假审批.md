# 请假审批

**优先级：重要。** 辅导员、分院长和院长按各自可见范围审批学生请假。

## 真实代码入口

- `SchoolService.applications(...)`：按用户角色返回可见申请；
- `ApiController.decision(...)`：`POST /approvals/{aid}/decision`；
- `SchoolService.decide(...)`：完成审批状态转换、记录日志和通知。

## 执行过程

1. 审批人读取待办申请，`visible(...)` 判断其是否能看到该学生和该学院的数据。
2. 审批人提交“通过/驳回”与意见。
3. 服务锁定申请并确认其仍为 `PENDING`，避免两人同时审批产生覆盖。
4. 事务更新申请状态、写入审批日志、通知学生；批准后相关课次可阻止自动缺勤写入。

## 向老师讲解的一句话

“审批使用服务端可见范围与状态机控制，申请只能从待审批变成通过或驳回，不能被重复审批。”
