# 课堂举手

**优先级：一般。** 用于保存学生在当前课次中的举手状态，便于教师查看课堂互动。

## 真实代码入口

- `ApiController.hand(...)`：`POST /lesson-sessions/{sid}/hand-raises`；
- `SchoolService.hand(...)`：校验身份并写入 `hands` 表。

## 执行过程

1. 学生点击“举手”或“放下手”。
2. 服务通过 `lesson(...)` 验证当前学生只能操作自己班级的课次。
3. `hands` 以课次和学生为键更新 `raised` 状态及更新时间，不重复新增记录。
4. 控制器向该课次的 SSE 订阅者发送刷新事件，教师课堂页面即时刷新。

## 向老师讲解的一句话

“举手不是纯前端动画，状态保存在数据库中；同课次教师通过 SSE 刷新看到学生的最新举手状态。”
