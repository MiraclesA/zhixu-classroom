# 考勤报表

**优先级：重要。** 为辅导员、分院长和院长提供指定日期范围内的考勤统计。

## 真实代码入口

- `ApiController.report(...)`：`GET /reports/attendance`；
- `SchoolService.report(...)`：聚合考勤数据并执行学院、班级数据范围授权。

## 执行过程

1. 管理角色提交开始日期和结束日期。
2. 服务验证日期区间，按当前用户角色限制可统计的学院或班级。
3. SQL 按课程、班级或学生聚合 `PRESENT`、`LATE`、`ABSENT` 等状态。
4. 前端把汇总结果显示为统计卡片和列表；学生与普通教师不能调用管理报表。

## 向老师讲解的一句话

“报表不信任前端传来的学院 ID，而是从已认证用户角色推导数据范围，再对考勤明细做聚合。”
