# 通知中心

**优先级：一般。** 将请假、审批、课堂互动等需要用户知晓的事件持久化保存。

## 真实代码入口

- `SchoolService.notify(...)`：创建通知记录；
- `SchoolService.notifications(...)`：读取当前用户的通知；
- `ApiController.notifications(...)`：`GET /notifications`。

## 执行过程

1. 业务方法在消息、请假或审批完成后调用 `notify(userId, message)`。
2. 服务向 `notifications` 插入接收人、正文和创建时间。
3. 用户请求通知接口时，服务仅按当前 Token 对应的用户 ID 查询，不能读取他人的通知。
4. 前端刷新后显示未读提示或通知列表。

## 向老师讲解的一句话

“通知是独立持久化数据，不依赖浏览器是否正好在线；用户下次登录仍能读取自己收到的通知。”
