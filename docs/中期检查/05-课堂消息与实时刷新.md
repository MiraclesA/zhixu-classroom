# 课堂消息与实时刷新

**优先级：重要。** 支持教师群发、师生私信，以及同一课堂页面的实时刷新。

## 真实代码入口

- `SchoolService.messages(...)`：读取当前用户可见的课堂消息；
- `SchoolService.message(...)`：校验消息类型、接收人和发送权限后写入 `messages`；
- `ApiController.events(...)`：建立 `text/event-stream` 的 SSE 连接；
- `ApiController.update(...)`：向同课次订阅者广播 `refresh`。

## 执行过程

1. 页面连接 `/lesson-sessions/{sid}/events`，控制器把连接保存到该课次的订阅集合。
2. 教师发送群消息，或教师/学生发送私信；服务检查发送人、接收人与课次的关系。
3. 服务保存消息并为接收人写入通知。
4. 控制器调用 `update(sid)` 广播刷新事件；浏览器收到事件后重新读取消息、座位等数据。

## 向老师讲解的一句话

“使用 SSE 实现服务器到浏览器的单向实时通知；消息正文仍通过普通 REST 接口读取，连接断开会被自动清理和重连。”
