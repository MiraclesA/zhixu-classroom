# 课表查询与课次调整

**优先级：重要。** 课表决定学生签到窗口和自动缺勤检查的时间基准。

## 真实代码入口

- `ApiController.timetable(...)`：`GET /timetable`；
- `SchoolService.timetable(...)`：按角色的数据范围读取课次；
- `ApiController.time(...)`：`PATCH /lesson-sessions/{sid}/time`；
- `SchoolService.reschedule(...)`：教师修改本课次教室、开始时间与结束时间。

## 执行过程

1. 登录用户按周请求课表。
2. `timetable(...)` 根据角色限制结果：学生看本班，教师看本人授课，辅导员/分院长看本学院，院长看全校。
3. 教师提交改课时间时，`reschedule(...)` 验证教师确实属于该课程、时间格式正确、结束时间晚于开始时间、教室长度合法。
4. 同一事务更新 `lessons` 的 `room`、`start_at`、`end_at`，并写入审计日志。
5. 事务提交后重新安排下一次自动缺勤检查，确保新时间生效。

## 向老师讲解的一句话

“课程是模板，`lessons` 是具体一次课；教师改的是某一次课的实际时间和教室，因此学生签到和缺勤判断都会自动跟着课次时间变化。”
