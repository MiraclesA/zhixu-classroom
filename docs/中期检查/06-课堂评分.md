# 课堂评分

**优先级：一般。** 教师可以为本人课程的学生记录课堂评分。

## 真实代码入口

- `ApiController.score(...)`：`POST /lesson-sessions/{sid}/scores`；
- `SchoolService.score(...)`：验证评分人、目标学生、分值和备注，并更新 `scores` 表。

## 执行过程

1. 教师提交学生 ID、分数与备注。
2. 服务确认当前用户是该课次的任课教师，目标学生属于课程班级。
3. 分数在服务端做范围校验，避免浏览器篡改任意数值。
4. 在事务中写入或更新当前课次、当前学生的评分记录，并通知同课次页面刷新。

## 向老师讲解的一句话

“评分权限由后端验证，教师只能给自己所授班级的学生评分，不能依赖前端隐藏按钮来限制。”
