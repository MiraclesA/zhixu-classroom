# 请假材料附件

**优先级：一般。** 学生可上传请假凭证图片，审批人只能查看自己有权限看到的材料。

## 真实代码入口

- `ApiController.upload(...)`：`POST /attachments`；
- `SchoolService.saveAttachment(...)`：保存附件；
- `ApiController.image(...)` 与 `SchoolService.attachment(...)`：授权后读取附件。

## 执行过程

1. 上传接口限制文件大小，检查 PNG/JPEG 文件头，并使用 `ImageIO.read(...)` 确认真实可读。
2. 服务把内容、媒体类型、原始名和上传人写入私有 `attachments` 表。
3. 读取时先验证“本人上传”或“审批人对关联申请可见”。
4. 响应设置 `Cache-Control: no-store`，避免浏览器缓存含个人材料的图片。

## 向老师讲解的一句话

“附件不是静态公开目录；上传和读取都由后端校验，读取权限与请假审批范围绑定。”
