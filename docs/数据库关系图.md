# 知序课堂数据库关系图

> 在 VS Code 中打开本文件后，按 `Ctrl + Shift + V` 即可预览关系图。
> 这份图由项目实际的 `V1__school.sql` 外键关系整理而来，可替代扩展收费版 ER 图用于答辩展示。

```mermaid
erDiagram
    departments ||--o{ classes : "包含"
    departments ||--o{ users : "归属"
    classes ||--o{ users : "学生所属"
    classes ||--o{ courses : "开设课程"
    users ||--o{ courses : "教师任教"
    courses ||--o{ lessons : "拆分为课次"

    lessons ||--o{ attendance : "产生考勤"
    users ||--o{ attendance : "学生考勤"
    lessons ||--o{ hands : "课堂举手"
    users ||--o{ hands : "学生举手"
    lessons ||--o{ messages : "课堂消息"
    users ||--o{ messages : "发送或接收"
    lessons ||--o{ scores : "课堂评分"
    users ||--o{ scores : "学生得分"

    users ||--o{ leave_applications : "提交请假"
    attachments o|--o{ leave_applications : "请假材料"
    leave_applications ||--o{ leave_targets : "关联课次"
    lessons ||--o{ leave_targets : "被请假覆盖"
    leave_applications ||--o{ teacher_reviews : "教师会签"
    users ||--o{ teacher_reviews : "教师审批"

    users ||--o{ tokens : "登录令牌"
    users ||--o{ audit_logs : "操作审计"
    users ||--o{ notifications : "系统通知"

    departments {
        bigint id PK
        varchar name
    }
    classes {
        bigint id PK
        bigint dept_id FK
        varchar name
        varchar major
        int grade
    }
    users {
        bigint id PK
        varchar account UK
        varchar name
        varchar role
        bigint dept_id FK
        bigint class_id FK
    }
    courses {
        bigint id PK
        varchar name
        bigint teacher_id FK
        bigint class_id FK
    }
    lessons {
        bigint id PK
        bigint course_id FK
        date lesson_date
        int period_no
        datetime start_at
        datetime end_at
    }
    attendance {
        bigint session_id PK, FK
        bigint student_id PK, FK
        varchar status
        datetime checked_at
    }
    leave_applications {
        bigint id PK
        bigint student_id FK
        varchar type
        varchar status
    }
```

## 答辩说明

- `lessons` 是考勤的核心：一门 `courses` 课程会拆成多个具体课次。
- `attendance` 使用 `(session_id, student_id)` 联合主键，保证一个学生每节课只有一条考勤。
- `leave_targets` 将一张请假申请关联到多个具体课次；审批完成后，对应 `attendance` 状态更新为 `LEAVE`。
- `audit_logs` 记录教师更正考勤、审批请假等操作，保证修改可追溯。
