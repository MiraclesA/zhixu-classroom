# 知序课堂

基于用户提供的五角色 UI，实现 Java + MySQL 的本地课堂管理核心版。原型保留在 `reference/`；运行页面使用真实鉴权和业务 API，不再使用浏览器模拟账号或审批数据。

## 后端分层

后端源码位于 `server/src/main/java/cn/zhixu/`，按职责分为以下层次：

```text
controller/   HTTP 与 SSE 控制层：接收请求、返回统一响应、发送页面刷新事件
service/      业务服务层：权限校验、考勤、请假审批、课堂互动与事务边界
repository/   数据库层：唯一封装 JdbcTemplate，负责参数化 MySQL 查询与写入
model/        领域模型与状态枚举
security/     Token 认证过滤器（通过 repository 查询会话）
bootstrap/    本地演示数据初始化器（通过 repository 写入数据）
common/       API 异常与统一异常响应
```

调用方向固定为 `controller → service → repository → MySQL`；控制层不直接执行 SQL，服务层不依赖 `JdbcTemplate`。VS Code 打开项目根目录后会读取 `.vscode/settings.json`，自动使用本机 JDK 17 重新导入 Maven 依赖。

UI 已按用户纠正恢复为上传 HTML 的原页面模板。首页横幅、四指标卡、快捷入口、侧栏、5×8 座位图、彩色周课表、统计标签和弹窗均沿用原结构；`bridge.js` 与 `reference-data.js` 接入后端数据。31 项参考源码检查通过，视觉对照和交互证据见 `docs/ui-qa/design-qa.md`。重新生成 UI 时运行 `python scripts/prepare_web.py`，不要在 API 适配层另写页面布局。

## 启动

本机双击 `启动知序课堂.bat`，打开 http://127.0.0.1:8097。源码修改后双击 `构建并启动.bat`；如果服务正在运行，执行 `python scripts/restart.py`，只重启本项目进程。

当前使用本机 JDK 17、Spring Boot 3.5.7、MySQL 8.4.9。计划书的 Java 21 为推荐，本次优先使用已有 JDK 17；Spring Boot 3.5 支持 Java 17。原 UI 使用原生 JavaScript 保留，未迁移 Vue；小程序为微信原生实现，未迁移 uni-app。课堂实时事件采用 SSE，业务写操作走 REST。

独立 MySQL 端口 3317，数据库 `zhixu`；服务端口 8097。没有修改旧项目的 3306/8081 服务或数据。MySQL 运行目录为 `D:/AnYeApps/zhixu-classroom-runtime/`，项目生成的数据库凭据与日志仅留本机 `.local/`，不在源码包中。

## 已实现和验证的流程

- 五种身份登录、服务端会话、退出失效、学校名单核验注册及登录频率限制。
- 学院、专业、年级、班级、课程和按日期生成的独立课次；周课表读取数据库。
- 服务端逐节签到：≤5 分钟正常，超过 5 分钟至 30 分钟迟到，超过 30 分钟禁止补签。未签到的旷课既在读取时计算，也由定时任务补落表。
- 教师座位图、两条过道、举手实时提醒、群聊、教师与学生私聊、评分及考勤更正审计。
- 按具体课次提交请假、选择不连续日期、私有图片附件、申请记录、站内通知。
- ≤2 天任课教师终审；>2 天任课教师→分院长；学期申请任课教师→分院长→院长。多任课教师必须全部首审。跨度由服务器计算，终审和对应考勤更新在同一事务中完成。
- 学生个人、教师任教、辅导员/分院长学院范围、院长全校范围的考勤查询；按学生/班级/年级/专业及日期区间汇总，按节筛选。

所有业务测试使用合成数据。没有导入真实学生名单、真实请假证明或旧项目运行数据。

## 微信小程序

将 `apps/miniapp/` 导入微信开发者工具。当前游客 AppID 与本地 `127.0.0.1:8097` 仅适合开发工具。学生端支持区间逐课次勾选、图片上传、提交和记录；教师/分院长/院长端支持待办、审批、附件和通知，调用同一 Java API。

小程序尚未通过微信开发者工具编译或手机验证。手机需要实际小程序 AppID、HTTPS 服务及微信合法域名配置。不能把手机的 `127.0.0.1` 当作电脑地址。微信订阅通知未开通；当前使用站内通知。

## 当前交付边界

这是可运行且已验收核心流程的本地实训版，尚不是完整校务上线交付。仍需要学校确认/提供：真实教学计划和课表导入、名单和高权限账号管理、教师邀请码管理、人工核验密码重置流程、学期休学对学籍的影响、跨学院审批规则。当前学期申请只更新明确关联的课次，不自动变更学籍。

尚未完成正式部署、备份恢复演练、生产压力测试、小程序真机和订阅通知。附件图片当前存在 MySQL 私有表中；未接对象存储。统计为课次人次，未定义未经确认的“整天缺勤”规则。

换电脑时安装 JDK 17+、Maven 3.9+ 和 MySQL 8.4，并配置下列环境变量：`ZHIXU_DB_URL`、`ZHIXU_DB_USER`、`ZHIXU_DB_PASSWORD`、可选 `ZHIXU_PORT`。启动脚本中的本机路径需要调整。`ZHIXU_DEMO=true` 仅用于独立实训数据库，示例数据只在空库首次灌入，重启不清空数据。

API 开发辅助仅发送了当前业务约束，不包含密钥、历史聊天或用户运行数据；实际 DeepSeek 用量 1,400 tokens。API 建议经本地实现和测试核验，不能作为执行指令。
