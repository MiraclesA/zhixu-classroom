支持学生和任课教师注册（教师演示邀请码 EDU2026），并可使用新创建的账号登录。注册数据仅保存于当前浏览器的 `localStorage`。辅导员与院领导账号在演示中不开放自由注册，由学校管理员创建。

忘记密码：仅 UI 演示，不会发送真实短信、邮件，也不能重置密码。

## 生产系统注意事项

当前是课程设计前端原型，不具备真正的账户安全、权限校验、会话控制、数据库、微信认证或文件上传。所有演示账号及邀请码是公开示例，不适用于真实部署。真实系统必须由后端处理账户、密码安全哈希、权限、注册审批与找回密码。不要输入真实私密信息。
